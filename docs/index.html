This website contains information about neuroinformatics research in France.

It was formerly the website of the INCF France national node. Following changes to the INCF membership structure, the node is no longer active, although many of its members are still active in INCF activities, and a number of French institutions are INCF members.

If you would like to be added (or removed) from the list of neuroinformatics researchers working in France, wish to edit your profile, or wish to add/remove a tool or service from the tool registry, please open an issue or pull request.
